# 🚀 RoleFlux

> A modern Job Aggregation Platform with AI-powered Resume Analysis.

RoleFlux simplifies job searching by aggregating job listings from multiple platforms into a single interface. It also provides AI-powered resume analysis using Google's Gemini API, helping users evaluate ATS compatibility and improve their resumes with personalized suggestions.

🌐 **Live Demo:** https://roleflux.tech

---

## ✨ Features

- 🔍 Aggregate job listings from multiple sources
- ⚡ High-performance job search with Redis caching
- 🤖 AI-powered resume analysis using Gemini API
- 📄 ATS compatibility scoring with personalized suggestions
- 🔐 Secure authentication with Firebase & JWT
- 📧 Email verification using Resend
- ❤️ Save and manage favorite jobs
- 📱 Fully responsive user interface
